## 📊 Projects

### [Retail Sales Analysis: Where Does the Business Make and Lose Money?](https://github.com/aswinck10/retail-sales-profit-analysis-sql)
**SQL · Python (Pandas) · Google Colab**

High sales don't always mean high profit. I used SQL to find which products, discount levels and regions drain profit, then turned the results into recommendations a retail manager could act on.

- **Key finding:** Tables and Bookcases lost $132,645; without these losses, profit would be about 8.7% higher.
- **Recommendation:** Fix or cut loss-making furniture and set a 5% discount limit, with manager approval above it.
